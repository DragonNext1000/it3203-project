Key Concepts

Seven ideas that make the rest of this site easier to follow.

Smart contract

Code stored on a blockchain that runs automatically when called, with results every node can verify.

Consensus

The method a network uses to agree on which transactions happened and in what order, such as proof of work or proof of stake.

Gas fee

The payment for computation and storage on a blockchain. Fees rise when the network is busy.

Blockchain trilemma

The challenge of improving security, decentralization, and scalability at the same time.

Rollup

A Layer 2 that executes transactions off-chain and posts the data to Layer 1 so the base chain can verify the results.

Fraud proof and validity proof

Optimistic rollups use fraud proofs to challenge bad batches. ZK rollups use validity proofs to show batches are correct.

Bridge

A tool that moves assets between chains or layers. Bridges are convenient but have been common targets for attacks.
