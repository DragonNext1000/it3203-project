Smart Contracts, Layer 1 and Layer 2: How Blockchains Run Programs and Scale

Abstract

Smart contracts are programs stored on a blockchain that run exactly as written, with no middleman. Base blockchains (Layer 1) such as Ethereum execute these contracts and keep them secure, but they can only process so many transactions. Layer 2 networks, mostly rollups, move most of the work off the main chain while still relying on it for security. Ethereum’s roadmap leans on this split, and it brings new risks to understand. This site explains what smart contracts are, how Layer 1 and Layer 2 differ, and why the split matters for cost, speed, and trust. A short quiz at the end lets you check what you learned.

Key Findings

  • Smart contracts remove the middleman, but bugs in them can be very costly.
  • Layer 1 chains trade off security, decentralization, and speed.
  • Rollups cut fees by batching transactions and posting the data to Layer 1.
  • Ethereum’s upgrades (Dencun, Pectra, Fusaka) have made Layer 2 data cheaper.
  • Bridges and rollup admin keys are the main extra risks of using Layer 2.
